Federated variant classification with population context

Three public sources join into one table, which splits into a held-out test set and three simulated hospitals. Each hospital trains locally, an NVFlare server averages the weights in a loop, the held-out set grades the result, then a patient query collects counts from every hospital and produces a verdict. Rows never leave a site. All numbers are illustrative.
